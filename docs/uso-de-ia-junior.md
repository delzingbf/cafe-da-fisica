- estruturação da tela de configurações do admin:
  Usei o Claude principalmente para pedir ajuda em como estruturar o código de forma eficiente, já que a tela tinha várias partes diferentes (e-mail de pedidos, troca de senha e a parte visual). Eu tinha uma ideia do que queria fazer, mas não sabia a melhor forma de organizar isso no código, então a IA me ajudou a pensar nessa estrutura.

  Também usei para tirar dúvidas de detalhes do TypeScript e do React, que são coisas que eu ainda não domino. Era mais para entender como escrever determinadas partes do que para gerar o código inteiro.

  Não tinha ideia de como fazer a tela conversar com a API para salvar o e-mail que recebe os pedidos, então pedi ajuda para entender esse caminho e conseguir implementar. Foi útil para entender como o front e o back se comunicam no projeto.

- questão das cores:
  Pedi para a IA implementar a troca da paleta de cores do site, mas o resultado não ficou 100% como a gente gostaria, então retornamos e deixamos por enquanto só a prévia visual das cores na tela de configurações.
